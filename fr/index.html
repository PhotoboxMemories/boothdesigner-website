Sur ton site en 5 minutes

Aucune connaissance en programmation n'est nécessaire. Choisis simplement comment tes clients accèdent au studio.

4

Créer toi-même

Une fois connecté, tu peux aussi créer tes propres modèles dans le studio et les télécharger en PNG.

Comment insérer le code

  • WordPress: Ajoute un bloc « HTML personnalisé » et colle le code dedans.
  • Wix: Ajouter → Intégrer → « Intégrer du code » et colle le code.
  • Jimdo: Ajoute un élément « Widget/HTML » et colle le code dedans.
  • Squarespace, Shopify & co. : utilise un bloc code ou HTML.

Exemple de code d'intégration

<iframe src="https://boothdesigner.de/studio/?b=ton-nom" style="width:100%;height:90vh;min-height:640px;border:0" title="Créer son design photobooth" loading="lazy"></iframe>

Tu trouveras ton propre code avec ton nom dans Mon BoothDesigner après connexion.

Questions fréquentes

Comment intégrer le studio à mon site web ?

Dans le tableau de bord, tu obtiens un lien et un code d'intégration. Tu colles le code sur n'importe quel site web (WordPress, Wix, Jimdo, Shopware …). Exemple :

<iframe src="https://boothdesigner.de/studio/?b=ton-nom" style="width:100%;height:90vh;border:0" title="Créer un design photobooth"></iframe>
Ai-je besoin du logiciel de photobooth Photobox Memories ?

Non. Tu peux télécharger chaque envoi en PNG prêt à imprimer avec zones photo transparentes et l'utiliser en overlay dans dslrBooth, Breeze Booth, Sparkbooth ou tout autre logiciel de photobooth. Avec Photobox Memories, la reprise se fait en un clic.

Mes clients peuvent-ils télécharger eux-mêmes les designs ?

Pas par défaut – ils t'envoient le design. Si tu le souhaites, tu actives le téléchargement dans le tableau de bord.

À qui appartiennent les designs ?

Les designs font partie de l'abonnement. Tu peux les utiliser pour tes prestations photobooth tant que l'abonnement est actif. La revente des fichiers de design comme modèles propres n'est pas autorisée.

Que se passe-t-il après l'essai ?

Après 14 jours, l'essai se termine automatiquement. Tu décides alors dans le tableau de bord si tu continues en mensuel ou en annuel. Aucun frais si tu ne souscris rien.

Pour quelles occasions existe-t-il des modèles de photobooth ?

Pour les mariages, anniversaires, fêtes, fêtes d'été, remises de diplômes et rentrées scolaires, EVJF/EVG, baby showers, baptêmes, communions et confirmations, fêtes d'entreprise, Noël et l'hiver ainsi que le Nouvel An, Halloween, le carnaval et Pâques. Plus de 420 mises en page de photobooth au total – et de nouvelles s'ajoutent régulièrement.

Quels formats et tailles d'impression sont disponibles ?

Chaque design existe en bande photo 2×6 pouces, en portrait 4×6, en paysage 6×4, en carré 5×5 et en couverture de magazine – prêt à imprimer en 300 dpi, avec un écran d'accueil assorti pour le photobooth.

Comment créer un layout photobooth ?

Choisir un template, saisir les prénoms et la date, ajuster couleurs et polices – c'est fait. Le layout photobooth se crée directement dans le navigateur, sur téléphone ou ordinateur, et s'enregistre comme modèle prêt à imprimer en 300 dpi. Avec le logiciel Photobox Memories, le layout arrive dans l'événement en un clic.

Qu'est-ce qu'un template photobooth ?

Un template photobooth est le modèle de mise en page dans lequel le photobooth place les photos des invités – avec fond, décoration, textes et zones photo. BoothDesigner propose plus de 420 templates que tes clients personnalisent eux-mêmes.
